1. Cómo Compilar el Instalador (.exe / .msi)

Convierte el código fuente en un archivo instalador listo para entregar al cliente.

Venematic está configurado con Tauri v2 + Rust. Esto genera instaladores ultraligeros (menos de 15 MB) que incluyen la base de datos SQLite local embebida sin que el cliente tenga que instalar servidores externos ni dependencias raras.

Paso a Paso para Generar el Instalador de Windows:

# 1. Abrir la terminal en la carpeta de escritorio cd venematic-desktop # 2. Compilar el ejecutable e instalador de Windows npm run tauri build
📁 ¿Dónde queda guardado el archivo final?
Al finalizar la compilación, Tauri creará automáticamente tu instalador en:
venematic-desktop/src-tauri/target/release/bundle/nsis/Venematic_2.0.0_x64-setup.exe
venematic-desktop/src-tauri/target/release/bundle/msi/Venematic_2.0.0_x64_es-ES.msi
Ese único archivo .exe o .msi es el que le entregas a tu cliente.

¿Y si vas a entregar la app para Teléfonos o Escáners Android?

# Compilar la app nativa Android (APK) con Capacitor npx cap sync android cd android && ./gradlew assembleRelease

El APK generado se guarda en android/app/build/outputs/apk/release/app-release.apk.

2. Cómo se Instala Directo en el Negocio

Procedimiento exacto cuando llegas a la panadería, charcutería, supermercado o restaurante.

💾 Paso A: Llevar el Instalador

Copia el archivo Venematic_Setup.exe en un pendrive USB o súbelo a tu Google Drive para descargarlo en la PC del cliente.

⚡ Paso B: Ejecutar e Instalar

Doble clic en el instalador. Hace la instalación limpia en Archivos de Programa y crea el acceso directo en el Escritorio en 10 segundos.

🔌 Paso C: Conectar Periféricos

Conecta la balanza por puerto USB/COM, la impresora de tickets USB de 58/80mm y la pistola lectora de código de barras.

🌐 ¿Requiere Internet para funcionar el día a día?
NO. Venematic es 100% Offline-First. La computadora del cliente factura, pesa, descuenta inventario y calcula cambio en Bolívares y Dólares aunque se caiga el internet o la luz.

3. ¿Cómo Funcionan las Claves de Activación?

Protección contra copias no autorizadas mediante huella digital física del computador.

Para evitar que un cliente te compre una licencia y luego copie el sistema en 5 computadoras o se lo pase a un amigo, Venematic utiliza el sistema HWID (Hardware ID Fingerprint) y criptografía asimétrica Ed25519 / HMAC-SHA256.

🧠 1. El HWID (Huella del Equipo)

Al instalarse, el sistema lee datos inmutables del procesador, placa madre y bios de la máquina y genera un código único (ej: VN8E-4A12-B9C0-33F1). No hay dos computadoras en el mundo con el mismo HWID.

🛡️ 2. La Clave de Producto Criptográfica

Tú generas una clave que firma matemáticamente: [HWID del cliente] + [RIF del negocio] + [Tipo de Plan] con tu clave secreta de creador.

🚫 ¿Qué pasa si el cliente copia el programa a otra PC?
Si el cliente copia la carpeta o la base de datos a otra computadora, el nuevo computador tendrá un HWID diferente. Al abrir Venematic, el sistema detecta que la firma no coincide y se bloquea de inmediato diciendo: "Licencia no transferible: HWID no coincide con esta máquina".

4. Flujo Comercial: Paso a Paso para Activar un Cliente

Este es el procedimiento que harás cada vez que vendas una copia de Venematic.

  • 1

    El cliente abre Venematic en su PC

    El cliente entra al menú Ajustes > Licenciamiento y HWID (o le aparece el aviso de activación). Allí verá su identificador único (ej: VN2A-98C4-7710-F012) y un botón que dice "Copiar ID".

  • 2

    El cliente te envía los datos por WhatsApp

    El cliente te escribe: "Hola, ya instalé el sistema. Mi RIF es J-40123456-0 y mi HWID es VN2A-98C4-7710-F012", y te envía el comprobante de pago de la licencia.

  • 3

    Tú generas la clave con el Keygen

    Tienes dos formas inmediatas de generar la clave:

    Opción 1: En tu propio Venematic (Visual)

    Abres tu Venematic, vas a Ajustes > Licenciamiento, abres la pestaña secreta de Keygen Maestro, pegas el HWID del cliente, su RIF y presionas "Generar Licencia".

    Opción 2: Desde tu consola (Script)

    Ejecutas en terminal:
    node scripts/key-manager.mjs sign VN2A-98C4-7710-F012 VIT

  • 4

    Le envías la clave al cliente y queda activado

    Le respondes por WhatsApp con su clave de producto (ej: VNK-VIT-PERP-8F32-41AB-9CD0-EF12).
    El cliente la pega en la casilla de activación, hace clic en "Validar y Activar", y el sistema se desbloquea de por vida de forma instantánea y 100% offline.
